# Forza Horizon 6 Rating Board

Интерактивная таблица для оценки участников в стиле Forza Horizon 6

## ✨ Возможности

- Добавление и редактирование участников (двойной клик по имени)
- Полностью настраиваемые варианты заездов
- Оценка по 5-балльной системе (Кузов, Покраска, Салон + заезды)
- Автоматический подсчёт итогов и определение лидера
- Красивый дизайн в стиле Forza Horizon
- Адаптив под разные экраны

## 🚀 Как пользоваться

1. Открой сайт: **[forza-rating-board](https://firo-98.github.io/forza-rating-board/)**
2. Нажми **"+ Добавить участника"**
3. Нажми **"+ Добавить заезд"** и выбирай из готовых вариантов или создавай свои
4. Выставляй оценки от 1 до 5 звёзд
5. Лидер автоматически подсвечивается

## 🎮 Функции

- Редактирование названий участников и категорий (двойной клик)
- Удаление заездов (крестик на карточке)
- Сброс всех оценок
- Сохранение результатов
- Адаптивный дизайн

## 🛠 Технологии

- HTML5
- CSS3 (с современными эффектами)
- Vanilla JavaScript
